# Savour & Spice

A modern, visually immersive restaurant website designed to showcase a menu and enable online ordering.

## Features
- Full-screen video background with warm gradient overlay.
- Glassmorphism design (frosted glass cards, blurred navigation).
- Dynamic menu grid with category filtering (Pizza, Pasta, Salads, Desserts).
- Interactive shopping cart with quantity controls and real‑time total updates.
- Checkout modal integrated with Formspree – orders submitted via AJAX (no page reload).
- WhatsApp chat bubble and scroll‑to‑top button for better UX.
- Fully responsive – optimized for desktop, tablet, and mobile.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, keyframe animations)
- Vanilla JavaScript
- Swiper.js (testimonials carousel)
- Font Awesome 6 icons
- Google Fonts (Montserrat, Outfit)
